Телефонные звонки

Разрешённый номер — телефон, на который звонит JARVIS и с которого он может принять вызов. Для входящего звонка набирайте номер SIM-карты в Q1.

Для автозвонка добавьте действие jarvis_q1.call в автоматизацию Home Assistant. Передача звука через SIM7600 зависит от прошивки.

Диагностика

Камеру можно проверить до сохранения. Остальные проверки используют применённые настройки.

Проверка микрофона длится одну секунду. Звук используется для измерения уровня. Проверка SpeechKit отправляет короткую тестовую фразу на синтез.
